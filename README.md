# The Daily Frequency

A personal curiosity-driven morning show.

## Site

When GitHub Pages is enabled from `main` / `(root)`, the site URL is https://wfletcher13.github.io/Daily-Frequency/ .

## Pilot capabilities

- Mobile-friendly listening console and transcript with selectable segments
- Narration using a device voice where supported
- October 15, 2026 pilot stories and curiosity detours

## Status

The daily ChatGPT briefing is scheduled separately and does not automatically update this website. Automated narrated daily publishing needs additional hosting configuration and a secure audio generation workflow. No existing repositories were modified.
